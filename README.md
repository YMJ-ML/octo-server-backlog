# Octo-Server PM Backlog

这是 Octo-Server 项目的产品管理需求库。

## 用途
收集和管理 octo-server 的 Bug 报告、功能需求、任务等。

## 工作流程
用户反馈 → 自动创建 Issue → 打标签分类 → 生成 PRD → PR Review → 决策（Accept/Reject/Wontfix）

## Label 体系
- 类型: bug / feature / enhancement / task / documentation
- 优先级: p0-critical / p1-high / p2-medium / p3-low
- 状态: needs-analysis / analyzed / in-review / accepted / rejected / wontfix
- 领域: auth / permission / message / group / channel / bot / api / database / performance
